# Product Catalog API

## Project Description
Simple Product Display API built with Node.js and Express. Serves 3 GET endpoints and a static frontend to view products.

**Technologies:** Node.js, Express, HTML, JavaScript

## Project Structure
product-catalog-api/
├─ .gitignore
├─ package.json
├─ README.md
├─ server.js
└─ public/
└─ index.html


## API Documentation

### GET /products
- **Method:** GET  
- **Description:** Returns an array of all product objects.  
- **Sample Response:**
```json
[
  { "id":1, "name":"Laptop", "category":"Electronics", "price":45000, "inStock":true }
]

`npm install`
`npm start`
